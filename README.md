# BoredlessConvo

An app to generate interesting conversation topics to help avoid awkward silences and boring conversations.

## Project Structure

- **frontend**: React Native/Expo mobile and desktop application
- **backend**: API server and data processing

## Getting Started

### Frontend

```bash
cd frontend/boredless
npm install
npx expo start
```

## Features

- Home screen with overview
- Topic generation
- Save favorite conversation topics
